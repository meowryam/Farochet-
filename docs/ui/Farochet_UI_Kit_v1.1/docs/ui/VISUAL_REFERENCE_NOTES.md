# Visual Reference Notes

The supplied/generated boards are visual references, not requirements documents.

## 1. `Farochet_Lavender_Garden_Homepage.png`

Use this as the primary reference for the Lavender Garden customer-homepage mood:

- lavender-led floral palette;
- large crochet-flower bouquet hero;
- refined serif headline and clean sans-serif body;
- warm cream canvas;
- petal/flower detailing at page edges;
- collection cards and sage custom-request section;
- lilac-toned footer.

Do **not** copy unsupported features visible in the image, including a free-shipping offer, cart/checkout, newsletter subscription, product review/rating claims, shipping/returns promises, or invented product claims. These are image-generation artifacts unless the PRD is formally changed.

## 2. `Earlier_Storefront_Admin_Layout_Reference_Not_Color_Standard.png`

Use only for the broad customer/admin composition and the way the admin workspace can sit beside the customer website. It was generated under an earlier colour direction and includes some visual artifacts. Its old palette is not authoritative.

## 3. `Previous_Approved_Layout_and_Floral_Detail_Reference.png`

Use only for the original layout/detail ideas and the crochet-flower decorative treatment that the team liked. Its old raspberry palette is superseded by Lavender Garden v1.1.

## Source-of-truth reminder

The exact colour values and placement rules are in `UI_GUIDELINES.md`. Functional screen content and allowed actions are in `UI_SCREEN_SPEC.md` and, ultimately, the PRD.
